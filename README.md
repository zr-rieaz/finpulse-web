**FinPulse Web** is a modern, privacy-focused Progressive Web Application (PWA) designed to give you complete control over your personal finances. Track daily expenses, monitor income vs. spending, analyze monthly/yearly savings trends, and set spending limits — all wrapped in a sleek, dark-themed interface.

🔗 **Live Web App:** [https://finpulse-red.vercel.app/](https://finpulse-red.vercel.app/)

---

## ✨ Key Features

### 📊 Comprehensive Dashboard & Analytics
* **Real-time Balance Overview:** Instant view of total balance, monthly savings, and yearly savings trends.
* **Visual Expense Breakdowns:** Dynamic donut/pie charts detailing expense percentages per category (Housing, Health, Food, Transport, Entertainment, Utilities, etc.).
* **Top Expense Categories:** Quick breakdown of high-spending areas for effective budget control.

### 📝 Detailed Transaction Management
* **Income & Expense Logs:** Log transactions with timestamps, amounts, and custom categories.
* **Search & Filter:** Instantly search through past transactions by name, category, or date.
* **Categorized Records:** Grouped view by days (e.g., Today, Yesterday, specific dates).

### 📓 Quick Notepad
* **Built-in Financial Notes:** Keep quick notes for budgets, shopping lists, or financial reminders categorized by *Finance*, *Budget*, *Shopping*, or *Personal*.

### ⚙️ Personalization & Settings
* **Multi-Currency Support:** Switch seamlessly between **BDT (৳)**, **USD ($)**, **EUR (€)**, **GBP (£)**, **MYR**, and **SAR**.
* **Multi-Language UI:** Fully localized in **Bangla (বাংলা)** and **English**.
* **Reminders & Alerts:** Built-in options for daily transaction reminders and budget limit warnings.
* **Custom Profile:** Personalized user profile setup with custom username configuration.

## 🛠️ Tech Stack

* **Frontend:** HTML5, Modern JavaScript / React.js
* **Styling:** Tailwind CSS (Modern Dark UI Theme)
* **Storage & Offline Support:** PWA Service Worker (`sw.js`), LocalStorage / IndexedDB
* **Hosting & Deployment:** [Vercel](https://vercel.com)

## 🚀 Getting Started

Follow these instructions to get a local copy up and running on your machine or Termux environment.

### Prerequisites
* [Node.js](https://nodejs.org/) (v16.x or higher)
* [Git](https://git-scm.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zr-rieaz/finpulse-web.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd finpulse-web
   ```

3. **Install dependencies (if applicable):**
   ```bash
   npm install
   ```

4. **Run the application locally:**
   ```bash
   npm start
   # or open index.html directly in your browser
   ```

## 📲 Installing as a PWA

FinPulse Web can be installed as a native app on Android, iOS, and Desktop:

1. Open [https://finpulse-red.vercel.app/](https://finpulse-red.vercel.app/) in your browser (Chrome, Edge, or Safari).
2. Click on **"Add to Home Screen"** or the **"Install App"** prompt in your browser menu.
3. Enjoy a full-screen, offline-capable app experience!
